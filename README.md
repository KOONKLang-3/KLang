# 🏫 ระบบจัดผังที่นั่งห้องเรียน (Classroom Seating Management System)

เว็บไซต์เลือกที่นั่งในห้องเรียน ดีไซน์พรีเมียม สไตล์ Modern Architectural Blueprint ออกแบบด้วยฟอนต์ `IBM Plex Sans Thai` มาตรฐานสถาบันการศึกษา พร้อมผังห้องเรียน 30 โต๊ะ หน้ากระดานห้องเรียน ระบบลงทะเบียนนักศึกษา และระบบแอดมินสำหรับตรวจดูคนจอง

---

## 🎯 ฟีเจอร์หลักของระบบ

1. **ผังห้องเรียน 30 โต๊ะ (100% ตรงตามความต้องการ)**:
   - **หน้ากระดานห้องเรียน (Front Blackboard)**: มีกระดานดำชอล์กคลาสสิก พร้อมแปรงลบกระดาน นาฬิกาดิจิทัล และปุ่มกดสลับเป็น **"โหมดสมาร์ทบอร์ดดิจิทัล (Smart Display)"** ได้
   - **จัดโต๊ะ 2 ฝั่ง (ฝั่งซ้าย 15 โต๊ะ / ฝั่งขวา 15 โต๊ะ รวม 30 โต๊ะ)**:
     - **ฝั่งซ้าย (Left Wing)**: โต๊ะ `L01` ถึง `L15` แบ่งเป็น **5 แถว แถวละ 3 ตัว** (ฝั่งริมหน้าต่างกระจก)
     - **ทางเดินกลาง (Center Aisle)**: ทางเดินตรงกลางห้องพร้อมลูกศรบอกทิศทางและเลขแถว 1–5 ชัดเจน
     - **ฝั่งขวา (Right Wing)**: โต๊ะ `R01` ถึง `R15` แบ่งเป็น **5 แถว แถวละ 3 ตัว** (ฝั่งติดผนังทางเดิน)
   - **ระบบไฟฟ้าและเครือข่ายประจำโต๊ะ**: แต่ละโต๊ะระบุจุดเชื่อมต่อปลั๊กไฟ 220V และสาย LAN Gigabit
   - **ประตูทางออกหลังห้อง**: มีสัญลักษณ์ประตู EXIT B และจุดรวมระบบเครือข่าย

2. **ระบบสมาชิก & ระบุตัวตนผู้จอง (Authentication & Identification)**:
   - **ลงทะเบียนนักศึกษาใหม่ (Register)**: ระบุชื่อ-นามสกุล, ชื่อเล่น, รหัสนักศึกษา, รหัสผ่าน พร้อมเลือกสีตราประจำตัว
   - **เข้าสู่ระบบ (Login)**: เข้าใช้งานด้วยรหัสนักศึกษา หรือชื่อผู้ใช้
   - แสดงสถานะที่นั่งและชื่อของผู้ใช้บนแถบเมนูด้านบนทันทีเมื่อล็อกอิน
   - **ตราประจำตัวอักษรย่อภาษาไทย**: ออกแบบด้วยสไตล์มินิมอลแบบ Linear/Notion (เช่น `ธส`, `กพ`) แสดงบนโต๊ะที่จองอย่างสวยงามเป็นระเบียบ

3. **ระบบผู้ดูแลระบบ / อาจารย์ประจำวิชา (Admin Management System)**:
   - เข้าสู่ระบบด้วยบัญชีแอดมิน:
     - **ชื่อผู้ใช้**: `admin`
     - **รหัสผ่าน**: `admin123`
   - **แผงควบคุมแอดมิน (Admin Center)**:
     - แถบ Progress Bar สรุปความจุห้องเรียนแบบ Real-time: จำนวนโต๊ะทั้งหมด, โต๊ะที่จองแล้ว, โต๊ะว่าง, อัตราการเข้าเรียน (%)
     - ค้นหาข้อมูลนักศึกษาได้ทันทีตามชื่อ, ชื่อเล่น, รหัสนักศึกษา หรือเลขโต๊ะ
     - ตารางตรวจสอบรายชื่อคนที่เลือกแต่ละโต๊ะ พร้อมเวลาที่ทำการเลือก
     - จัดการรายโต๊ะ: **ปลดล็อคที่นั่ง / สั่งล็อคโต๊ะชำรุดห้ามจอง**
     - **ส่งออกข้อมูลเป็นไฟล์ Excel/CSV** ได้ใน 1 คลิก
     - **พิมพ์ใบเช็คชื่อตามผังที่นั่ง (Print Seating Chart)** สำหรับติดหน้าห้องเรียน
     - แก้ไขข้อความประกาศบนหน้ากระดานได้โดยตรง

4. **ระบบเสียงสัมผัส (Tactile Sound FX)**:
   - สังเคราะห์เสียงเคาะสัมผัสนุ่มนวล (Tactile Tap) และเสียงกระดิ่งนวลหู (Marimba Chime) เมื่อทำการเลือกโต๊ะ พร้อมปุ่มเปิด/ปิดเสียง

## 🚀 วิธีเปิดใช้งาน

### วิธีที่ 1: รันผ่าน Node.js (แนะนำ)

เปิดโปรแกรม PowerShell หรือ Terminal ในโฟลเดอร์นี้ แล้วสั่ง:

```bash
node server.js
```

หรือ:

```bash
npm.cmd start
```

จากนั้นเปิดเว็บบราวเซอร์ไปที่:
👉 **http://localhost:3000**

---

### วิธีที่ 2: ดับเบิ้ลคลิกเปิดไฟล์ได้ทันที (Standalone)

คุณสามารถดับเบิ้ลคลิกไฟล์ `index.html` เพื่อเปิดใช้งานใน Google Chrome, Microsoft Edge หรือบราวเซอร์ใดก็ได้ทันที

## 🔑 บัญชีผู้ดูแลระบบ (Admin Account)

| บทบาท | ชื่อผู้ใช้ / รหัส | รหัสผ่าน | สิทธิ์การใช้งาน |
|---|---|---|---|
| 🛡️ อาจารย์ / แอดมิน | `admin` | `admin123` | ดูทุกคน, ปลดล็อคโต๊ะ, สั่งล็อคโต๊ะ, แก้กระดาน, ส่งออก CSV, พิมพ์ใบเช็คชื่อ |
| 🧑‍🎓 นักศึกษาทั่วไป | ลงทะเบียนผ่านหน้าเว็บ | กำหนดเอง | เลือกโต๊ะ, ยกเลิกโต๊ะตัวเอง, ดูข้อมูลเพื่อน |
